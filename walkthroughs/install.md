## Install ESBMC

ESBMC is a separate binary, not bundled with this extension.

**ESBMC: Install latest version** downloads the newest release from
[github.com/esbmc/esbmc](https://github.com/esbmc/esbmc/releases/latest) and puts
it in `$HOME/bin/esbmc`.

If you already have ESBMC on your `PATH`, the extension uses that instead and
tells you which version it found.
